# ADR-0007 — Three Workstation services

English · [简体中文](0007-three-service-deployment.zh-CN.md)

Full Compose runs Runtime, Gateway and Browser and reuses the operator's Traefik. Gateway keeps the Go console, Provider and Selkies input gate as separate processes in one container. Provider control and the input gate listen on Gateway loopback. Calls on the workstation network use the Compose service names `runtime`, `gateway` and `browser`. The credential-protected MCP listener is `gateway:8080`. Traefik selects Gateway's proxy interface through `dsh-workstation-gateway-edge`, so HTTP and MCP can use port 8080 on their respective interfaces. [Issue #36](https://github.com/sagehou/dsh-workstation/issues/36) · [Issue #43](https://github.com/sagehou/dsh-workstation/issues/43)

The single operator shares DSH and Chromium state, so Runtime, Gateway and Browser use one `workstation` network. Traefik joins it for DSH and Selkies HTTP and reaches Gateway through the existing proxy network. Selkies HTTP assets are reachable on `workstation`. Browser's custom init script restricts Selkies data WebSockets and token administration to Gateway's workstation address on both Nginx listeners. Selkies itself listens on Browser loopback. [Issue #37](https://github.com/sagehou/dsh-workstation/issues/37) · [LinuxServer custom scripts](https://docs.linuxserver.io/general/container-customization/#custom-scripts) · [Pinned Nginx template](https://github.com/linuxserver/docker-baseimage-selkies/blob/6379480bcbd4ba42c1f5d4ab5eca49304fdedf83/root/defaults/default.conf) · [Pinned Selkies launcher](https://github.com/linuxserver/docker-baseimage-selkies/blob/6379480bcbd4ba42c1f5d4ab5eca49304fdedf83/root/etc/s6-overlay/s6-rc.d/svc-selkies/run)

LinuxServer starts the CDP relay through `/custom-services.d`. The relay runs as Chromium's `abc` account and writes a Unix socket that Gateway mounts read-only. Chromium's debug TCP listener stays on Browser loopback. [LinuxServer custom services](https://docs.linuxserver.io/general/container-customization/#custom-services) · [Pinned Chromium source](https://github.com/linuxserver/docker-chromium/tree/4ec00555069627093b9110daff841d363f9a95f8)

Gateway and its browser helpers share a container trust boundary. Restarting Gateway closes its proxy and MCP connections. The Browser profile, Gateway SQLite data and Provider fence stay on their existing volumes. Production Compose starts with Agent browser tools disabled. The full CI fixture exercises the existing lease and input checks with an explicitly enabled MCP listener. [Input gate design](0005-release-held-input-at-selkies.md)
