# M1 — Runtime 与首次私有启动

[English](M1.md) · 简体中文

[M0 的证据](M0-evidence.zh-CN.md)支持交付 Runtime 及其版本管理器。先交付最小可用功能：在同一个回环源下提供官方 DSH Web 和人工操作的 Selkies，远程通过 SSH 隧道访问。Runtime、工作区与 Chromium 数据保存在不同的卷。新装时选择一个确切的 DSH 版本；修改初始版本不会更新已有部署。

第一次交付沿用 M0 的固定版本：Node 24.22.3、pnpm 11.28.5、DSH 0.2.2-rc.1（版本切换和回滚也使用了 0.2.2-rc.5），LinuxServer Chromium 和 Traefik 按摘要固定。[GitHub 托管运行器上的 `fe91e89`](https://github.com/sagehou/dsh-workstation/actions/runs/44474103563/job/135390351014)通过了 `bash deploy/ci-preview.sh`。未认证访问 DSH 返回 401；通过同一回环 Traefik 端口访问时，已认证的 DSH 返回启动页面，`/browser/` 返回 HTML。也验证了离线维护锁、一次拒绝切换、成功切换与回滚，以及不重建镜像时的容器重建和工作区持久化。运行产出了[可加载的 Runtime 镜像和日志](https://github.com/sagehou/dsh-workstation/actions/runs/44474103563/artifacts/14505771617)。

可按[私有预览部署指南](../../deploy/README.zh-CN.md)使用该镜像。未记录在使用者主机上的部署。

在此阶段，公网发布还需要 ADR-0003 的 Go/SQLite ForwardAuth 服务、HTTPS 源和实际部署主机。私有 Compose 文件不能绑定公网接口。浏览器 Provider 是通过官方 MCP 与 DSH 对接的独立集成。初期交接限定为一位使用者先结束输入，再显式交接控制权。保留已按住输入的验证发现，等待官方侧栏生命周期 API。
