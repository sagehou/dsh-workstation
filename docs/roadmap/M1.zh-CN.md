## 预览范围

- 官方 DSH Web 与人工操作的 Selkies 共用一个回环源，远程访问走 SSH。
- Runtime、工作区和 Chromium 数据分别用独立卷。新装时选择确切 DSH 版本，已有部署沿用保存的选择。
- 固定 Node `24.22.3`、pnpm `11.28.5`、DSH `0.2.2-rc.1`，按摘要固定 LinuxServer Chromium 和 Traefik。切换与回滚另测了 DSH `0.2.2-rc.5`。[镜像摘要](M0-evidence.zh-CN.md#确切的上游版本)

## 公网后续
