## Preview scope

- Official DSH Web and manual Selkies share one loopback origin. Connect from another machine over SSH.
- Runtime, workspace, and Chromium data use separate volumes. A fresh install selects an exact DSH version. Existing deployments keep their stored selection.
- Pin Node `24.22.3`, pnpm `11.28.5`, DSH `0.2.2-rc.1`, LinuxServer Chromium, and Traefik by digest. Switch and rollback also exercised DSH `0.2.2-rc.5`. [Image digests](M0-evidence.md#exact-upstream-versions)

## Public follow-up

Keep the preview bound to loopback. Public access requires Go/SQLite ForwardAuth, HTTPS, and an operator deployment target. The Browser Provider connects through official MCP. The initial handoff assumes the operator finishes input and transfers control explicitly. Held input and the native Sidebar remain open.
